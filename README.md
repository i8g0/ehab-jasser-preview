# إيهاب الجاسر — ثيم سلة

ثيم فاخر لمتجر عطور إيهاب الجاسر، مكتوب بنظام **Salla Twilight** (Twig + CSS + JavaScript). معه معاينة تحاكي سلة وتعمل على Vercel، حتى يشوف العميل الموقع قبل التركيب.

```
theme/        ← الثيم نفسه، هذا اللي ينتقل لسلة
preview/      ← محاكي سلة للمعاينة فقط (لا يُنقل)
design-original/  ← ملفات التصميم الأصلية المصدّرة (مرجع)
```

## التشغيل محليًا

```bash
npm ci
npm run dev      # يبني ويفتح http://localhost:5500 ويعيد البناء مع كل تعديل
npm run build    # يبني نسخة Vercel في dist/
```

## النشر على Vercel

المشروع جاهز: `vercel.json` يحدد أمر البناء (`npm run build`) ومجلد الإخراج (`dist`). اربط المستودع بـ Vercel أو نفّذ `vercel` من المجلد.

## النقل إلى سلة

1. أنشئ ثيم جديد من ثيم Raed الرسمي: `salla theme create` (Salla CLI).
2. انسخ محتويات `theme/` فوقه:
   - `twilight.json` ← يستبدل الملف الموجود (فيه ١٢ مكوّن للرئيسية + إعدادات الثيم).
   - `src/views/**` ← القوالب (الرئيسية، المنتج، السلة، الهيدر، الفوتر، المكوّنات).
   - `src/assets/js/app.js · home.js · product.js · cart.js` ← نفس أسماء ملفات Raed، تستبدلها مباشرة. ملفات `ej/` مجلد جديد بجانبها.
   - `src/assets/styles/app.css` ← استورده من ملف الستايل الرئيسي في Raed (`@import './app.css';`) أو اجعله المدخل.
   - `src/assets/images/logo.png` و `src/locales/*.json` (ادمج مفاتيح `ej` مع ملفات Raed).
3. `salla theme preview` للتجربة على متجرك التجريبي، ثم `salla theme publish`.
4. من محرر الثيم في سلة: رتّب مكوّنات الرئيسية، ارفع الصور، واختر المنتجات لكل قسم.

### ما يجب ضبطه في لوحة سلة

| الميزة | كيف تُضبط |
|---|---|
| الاسم اللاتيني تحت اسم العطر (VELOUR) | حقل **العنوان الفرعي** للمنتج (`product.subtitle`) |
| شارة «الأكثر طلبًا / إصدار حصري» | حقل **عنوان العرض الترويجي** (`product.promotion_title`) |
| فلاتر البوتيك | تُبنى تلقائيًا من **تصنيف** كل منتج |
| حرف البوصلة (N / E / S / W) | أول حرف من العنوان الفرعي (EAST → E) |
| رقم «سنوات» | من العنوان الفرعي (THREE YEARS → 3) |
| هرم العطر في صفحة المنتج | أسطر في وصف المنتج تبدأ بـ `المقدمة:` `القلب:` `القاعدة:` ثم المكوّنات، ثم ` — ` وجملة وصف |
| لون صفحة المنتج | وسم (tag) على المنتج: `tone-amber` · `tone-noir` · `tone-rose` · `tone-ember` · `tone-pearl` |
| قائمة الهيدر والفوتر | من **القوائم** في سلة (`<salla-menu>`) |
| الشريط العلوي، الشاشة الافتتاحية، النغمة، التوهّج | إعدادات الثيم |

### نقاط تحقق عند أول تركيب

كل التعامل مع سلة محصور في ملف واحد: `theme/src/assets/js/ej/store.js`. أسماء الدوال مطابقة لتعريفات حزمة `@salla.sa/twilight` (`cart.addItem / updateItem / deleteItem / details / submit` و `cart.event.onUpdated`)، لكن تحقّق على المتجر التجريبي من:

- شكل استجابة `salla.cart.details()` (الملف يقرأ `product_name` و `product_image` وله بدائل).
- دالة `link('cart')` في القوالب، وإن لم تتوفر استبدلها بـ `{{ store.url }}/cart`.
- فورم «القائمة الخاصة» لا يرسل الأرقام لأي جهة؛ اربطه برابط واتساب أو تطبيق نشرات من حقل الرابط في المكوّن.

## ما يخص المعاينة فقط

`preview/` يحاكي دور سلة: يقرأ القيم الافتراضية من `twilight.json`، يملؤها ببيانات متجر تجريبي (`preview/store/data.mjs`)، ويوفّر بديلًا مبسّطًا لـ `window.salla` ولمكوّنات `<salla-*>` (السلة محفوظة في المتصفح). زر «إتمام الطلب» في المعاينة يعرض رسالة بدل صفحة الدفع.
